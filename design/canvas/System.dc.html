Roman Urdu is the default, and it is Latin script — one family across the whole ramp, no bidi, no shaping, no Nastaliq metrics. English is a switch, not a second design. Nastaliq lands later as a third locale; the ramp already carries the line-height headroom for it.

Numerals are always Latin 1234, never ۱۲۳۴. Unicode CLDR defaults ur-PK to latn; only ur-IN uses arabext. Money is Plex Mono with tabular-nums, so digits hold a column and never jitter as they tick. Stored as integer paisa — the UI never sees a float.
